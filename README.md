# Palia Share

**Fast. Simple. Secure.** — Android file sharing by Shanpalia.

## Included
- White + mint modern UI
- Send and Receive screens
- Local Wi-Fi phone-to-phone streaming transfer
- Multiple file selection
- QR code showing receiver endpoint
- Transfer progress and history
- PaliaAPK HUB update/store entry
- Android system networking permissions

PaliaAPK HUB: https://shanpalia.github.io/WebsitePaliaAPK_V.2/

## Build
GitHub Actions generates the Android project and builds a debug APK on every push to `main` or manual workflow dispatch.

## Note
This first build is a local-Wi-Fi transfer MVP. Automatic remote push update notifications require a push provider configuration such as Firebase Cloud Messaging and its project credentials; those are intentionally not hard-coded into the public repository.
